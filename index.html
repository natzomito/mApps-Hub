      Witaj w mApps Hub

      Jedno miejsce na wszystkie Twoje mini-aplikacje HTML. Bez sklepu, bez kont, bez chmury — wszystko zostaje na tym telefonie.

      ➕

      Dodawaj własne

      Poproś dowolny LLM o jednoplikową mini-aplikację HTML, wklej kod albo wybierz plik z telefonu. Możesz też ustawić własną ikonę z galerii.

      🔒

      Offline z założenia

      Każda apka startuje z zablokowanym dostępem do sieci — to gwarancja przeglądarki, nie obietnica. Internet włączasz sam, dla pojedynczej apki, tylko gdy jej ufasz.

      To jest otwarty projekt

      mApps Hub jest w pełni open source (EUPL-1.2) i zawsze będzie darmowy. Masz własną mini-aplikację? Dodaj ją do repo przez Pull Request — inni ją zainstalują jednym dotknięciem.
